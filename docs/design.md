# Tier 家庭 NAS 设计

## 入口和所有权

Windows → SMB → Samba → Linux FUSE → Rust 核心。部署使用仓库内的 Samba 共享配置，关闭该共享的 oplocks，让可写打开到达服务端；挂载点检查失败时 Samba 拒绝连接。管理界面仅监听回环地址。家庭用户的登录与共享权限由 Samba 处理。

SQLite 存放命名空间、策略、对象位置及写入确认状态。稳定的文件 ID 与父目录 ID、名称共同表达目录树。重命名修改目录关系；删除后同名重建产生新 ID。目标盘上的每个副本都是完整的普通文件，可以独立读取，也能凭快照恢复逻辑路径。受管盘只支持离线只读提取。

## 写入和发布

同一对象允许一个可写句柄。Tier 在第一次修改前记录持久化标记。打开的句柄共享该对象的临时文件；普通写更新临时文件，flush、同步写和最后关闭按生效策略确认。确认需要已写足规定数量的目标、同步文件和目录、提交元数据。失败的文件由管理员删除后重传。服务重启时，残留标记标识未确认内容；后台复制和归档跳过它。

本地副本使用独立对象位置，成功发布后才能回收旧位置。前台修改优先，后台复制结束时重新检查对象身份、内容摘要、写入状态和策略。覆盖采用 LWW。旧任务无法发布为新内容，也不会把已删除的路径重新挂回。删除或替换前，先保存目标写句柄中尚未提交的内容；成功后回收站保留该内容。已删除对象上的写入会返回失效错误，读句柄仍可读此前打开的数据。Windows 通常拒绝替换仍有打开句柄的目标，应在关闭目标后完成替换。

## 放置、回收和修复

暂存、长期、归档都是策略角色，设备介质不参与判断。本地放置和归档各自继承最近的目录绑定。移动或修改策略后，后台根据新目标补齐再回收。安静期从最后一次内容提交计算，目录改名不重置它。直接双写要求两个目标都确认；单份暂存只提供该份的设备保障。可为暂存失败时的直写独立指定确认份数。

本地写前按输入长度检查容量并在已核对身份的目标上预分配实际空间。同域目标需要显式接受风险；确认和后台放置均优先选择尚未使用的健康故障域。健康报告同时给出通过校验的目标及故障域数。低高水位控制回收时机，前台每个目标最多尝试 8 个候选；后台每轮每个目标最多检查 32 个、释放一个。前台仅使用仍有效的内容校验记录判断其他副本，空间无法及时腾出则执行失败或直写策略。底层设备 I/O 的耗时取决于设备。

健康核对检查完整 SHA-256。校验记录绑定文件系统身份、inode、长度及变更时间，元数据变化或缓存到期后重新计算。活动写入、残留的未确认写入、安静期、最近被取消的复制和仅远端存储可分别观察。修复使用同一套放置逻辑；首次放置独立于故障修复的宽限期和人工触发策略。

## 归档、召回和删除

归档后端采用 WebDAV，可使用 OpenList。上传使用独立键并读回校验。最后一份本地内容只有在目录策略允许、归档份数达标、选中的远端内容已重新校验、文件及策略仍匹配时才释放。仅远端文件打开时先为已知长度预留临时文件空间，再接收并校验远端字节。网盘失联时，已回收本地副本的文件需要等待网盘恢复。

删除立即移除共享路径并创建有 TTL 的回收条目。恢复检查目标目录和名称冲突，支持另选路径。管理界面展示原路径、逻辑大小、到期时间及各本地目标占用；到期或主动清理后按引用回收底层对象。

## 快照与灾后恢复

SQLite 对每次改变被备份元数据的已提交事务递增一次序号。对每个备份目录，首份快照立即发布；以后按第一笔尚未备份的变更时间或累计提交数触发，先满足者生效。无变化跳过。同轮使用一致性读事务生成的快照，目标目录身份匹配后独立发布，记录成功序号、落后量、成功时间和失败原因。保留最新若干份，可额外保留指定 UTC 小时、天窗口内每个时间段最新的一份。

JSON 保存格式版本、系统 ID、目录树、策略、目标、当前副本和回收条目，外层校验和覆盖元数据。作为数据目录清单，它不延长历史内容的保留期。导入总是先核对现有设备和当前归档对象；报告列出可验证内容、离线目标、缺失副本、摘要损坏、未确认写入及未认领对象。默认仅在预检干净时向新的数据库发布。管理员审阅报告后可以显式接受降级恢复。显式映射到身份错误的设备始终失败。恢复会保留系统 ID 和文件 ID，并为后续快照建立独立历史，防止分叉提交复用同名备份。旧历史可单独清理。单盘提取只读，不要求连接归档服务。

## 验收边界

| 验收条件 | 可重复运行的检查 |
|---|---|
| 单写者、局部写、刷新、替换、删除时保留最新内容 | `tests/windows-smb.ps1` 和 `tests/smb-smoke.sh`，分别按 Windows 与 Linux 打开句柄的语义断言 |
| 双写、延迟放置、故障域选择、恢复继承、Unicode 名称唯一性 | `cargo test --test local_store --test domains --test namespace` |
| 满盘失败或直写、卸载后不误写空挂载点 | `tests/capacity-smoke.sh` 在 8 MiB 文件系统中制造磁盘满；`tests/device-smoke.sh` 卸载并重挂 ext4 镜像 |
| 多目标快照、单盘提取、严格或降级恢复、保留回收站、从旧快照分叉 | `cargo test --lib backup::tests` 与 `cargo test --test lifecycle --test recovery --test recovery_branch` |
| 远端校验失败保留本地、归档对象丢失后修复、远端召回 | `cargo test --test archive`；OpenList 的本地存储驱动可验证真实 WebDAV 协议链路 |

真实网盘供应商、实际物理介质故障和各 Office 应用的保存行为需要在对应部署环境中验收。
